# AI tutor for Programming for Geoscientists

Use this page to give a web-capable AI assistant the course context it needs to
help you learn Python. The complete material is available here from the start of
the course. The tutor uses the [session timetable](ai-helper/SESSION-SCHEDULE.md)
and your own progress to choose an appropriate level.

Copy this into a new chat, then add your question:

> Please be my EART40003 Programming for Geoscientists tutor. Read
> https://marksutton.github.io/EART40003-Programming-for-Geoscientists/ai/
> and follow its tutor instructions. Read the timetable, teaching guidance and
> Thonny environment briefing, then use the relevant session handouts and
> demonstrations when answering. Tell me if you cannot open anything. Help me
> learn and debug my own code; do not complete course exercises for me.

You can tell the tutor which session you have reached, share your current
exercise wording, or paste the code and error you want help with. If your AI
cannot reliably read the linked pages, upload the
[complete tutor ZIP](eart40003-ai-tutor.zip) and use the same prompt.
