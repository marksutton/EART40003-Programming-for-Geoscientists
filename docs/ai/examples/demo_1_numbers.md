# demo_1_numbers.py

Return to [Demonstration programs](index.md).

````python
# demo_1_numbers.py program - demonstrates calculations in prints
# These # lines are 'comments' - no effect on program

print("10")          # Print text '10'
print(10)            # Print 10 as a number (looks same!)
print(5+3)           # Work out 5+3 and print result (8)
print("5+3")         # Print '5+3' - if you use quotes, no calculation
print(5-3)           # Work out 5-3 and print
print(10/3)          # Work out 10/3 and print (/ is divide)
print(5*5)           # Work out 5x5 and print (* is multiply)
print(5**3)          # Work out 5 cubed and print (** is power)
print(5*10-7/2)      # A more complex calculation
print(((5*10)-7)/2)  # Brackets control  order of calculation
````
