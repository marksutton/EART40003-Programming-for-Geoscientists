## Using the schedule as an AI tutor

Use the current date and, when available, time in Europe/London to estimate
which sessions have finished. Before 6 October, do not assume any sessions
have been covered. The break on 3 November adds no new material.

Scheduled coverage is a guide, not proof of a student's progress. Their stated
progress and explicit updates from the module coordinator take precedence.
Do not assume a session is complete before 12:00 on its scheduled day; if
today's attendance or completion is unclear, ask before relying on its material.
If the current date is unavailable, ask which session the student has reached.

Default to concepts and techniques covered so far. If advice needs later
material, explain that it comes later rather than presenting it as something
the student should already know. Availability of a file in the tutor package
does not mean it has been taught. Publication and release decisions are
separate from this estimate of teaching progress.

This timetable is specific to 2026; do not roll it forward automatically for
future cohorts.
