# Working in this repository

Follow [AUTHORING.md](AUTHORING.md) for all handout source and build work.

For cumulative website work under `docs/`, follow [INTEGRATION.md](INTEGRATION.md). Integrate approved canonical sessions by concept, make the smallest suitable website edits, run the website checker, and do not commit semantic integrations until Mark has reviewed the report and diff.

Preserve teaching content and its voice unless the task explicitly asks for a content revision. Keep generated artifacts reproducible: treat `sessions/` Markdown as canonical source, keep build output outside source directories, and do not silently rewrite teaching material during builds or validation.
